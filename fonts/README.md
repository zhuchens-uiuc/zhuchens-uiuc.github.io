# Website fonts

The page uses Source Sans 3 for body text, labels, controls, and inline research
illustrations, and Source Serif 4 for the name and section/project headings.
The favicon initials are fixed outlines from Source Serif 4.

Both font files are served locally. They are the unmodified Latin WOFF2 files
provided by Google Fonts; the page makes no runtime Google Fonts requests.

- Source Sans 3: variable weight axis 200–900; CSS uses 400–700.
- Source Serif 4: variable weight axis 200–900; CSS uses 400–600.
- Total font transfer: 79,564 bytes before HTTP compression.
- `sources.json` records the exact download URLs and SHA-256 checksums.
- `SourceSans3-OFL.txt` and `SourceSerif4-OFL.txt` contain the font licenses.

Upstream sources:

- https://github.com/adobe-fonts/source-sans
- https://github.com/adobe-fonts/source-serif
- https://github.com/google/fonts/tree/main/ofl/sourcesans3
- https://github.com/google/fonts/tree/main/ofl/sourceserif4

The included Latin subset covers all characters currently visible on this site.
For new languages or additional characters, add the appropriate upstream subset
instead of relying on an unverified system fallback.
